# Product

Why the project exists, for whom, and how success is measured. Written by hand; every figure names its source.

| File | Holds | Usually written in |
| --- | --- | --- |
| `problem-brief.md` | The problem, who has it, evidence and sizing with sources | Scaffold or Discovery task 1 |
| `personas.md` | Primary and secondary users, their jobs to be done | Discovery |
| `prd.md` | Requirements and acceptance criteria for the first release | Discovery |
| `data-plan.md` | What data is used, where it comes from, synthetic-data rules | Discovery |
| `metrics.md` | Each metric: definition, baseline, how it is computed | Discovery |
| `glossary.md` | Agreed terms, one definition each | Any time a term is disputed |

Rules: label assumptions as assumptions; no real personal data; link the decision record when a product choice changes the design.
