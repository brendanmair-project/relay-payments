# Evaluation

Measured results and exactly how they were produced, so anyone can rerun them.

| File | Holds |
| --- | --- |
| `method.md` | Questions, datasets (synthetic or public), baselines, metrics and tolerances |
| `results.md` | Numbers with the commit, seed and command that produced them |
| `images/` | Charts used in results and the README |

Rules: state when data is synthetic; compare against a stated baseline; never report a number you cannot reproduce from the repository.
